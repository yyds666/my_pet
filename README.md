# 毕业僵尸跳桌宠

基于人物参考照片制作的 Codex 兼容动画桌宠。

## 文件说明

- `spritesheet.webp`：v2 透明背景动画图集（1536 × 2288），包含 9 种标准动作和 16 个环视方向。
- `pet.json`：桌宠配置文件。
- `contact-sheet.png`：所有动作帧总览。
- `previews/`：九种动作的 GIF 预览。
- `validation.json`、`review.json`：自动与视觉质检结果。

## 动作

待机、左右移动、挥手、僵尸跳、失败、等待、工作与检查。其中左右移动已重制为双臂前伸、双腿并拢、身体直立的完整僵尸跳，不再使用单腿跑步动作。

## 放大与缩小

Codex 桌宠和 Windows 互动版现在共用同一个尺寸基准：

1. 打开 Codex 的“设置”。
2. 进入“Pets（桌宠）”。
3. 在“Appearance（外观）”中拖动“Pet size（宠物大小）”滑杆。

Windows 互动版每秒读取一次 Codex 的本地宠物尺寸设置，范围同样是 80–224 像素，因此在 Codex 中调整后会自动应用到正在运行的互动版。

单击人物打开想法面板，底部的 `−`、`+` 按钮可以在 Codex 尺寸基础上做临时偏移；点击“跟随 Codex”会清除偏移，恢复与 Codex 完全一致。偏移保存在 Codex 宠物目录中的 `windows-runner.json`。

## 共用一份 Codex 宠物包

Windows 启动器现在直接运行 `~/.codex/pets/graduate-zombie/interactive_pet.py`，并从同一目录读取图集、四向帧和运行配置。以后更新该 Codex 宠物目录中的资源或 Windows 交互代码，桌面启动器会自动使用新版，不再需要维护第二份运行文件。

Codex 原生内部功能仍由 Codex 应用实现，无法自动变成 Python 功能；但人物资源、尺寸设置以及放在共享运行器中的后续交互功能均只需更新这一个 Codex 宠物包。

## 四向互动版（Windows）

Codex 自定义宠物格式只负责精灵图和标准状态动画；官方桌宠运行器暂不支持在 `pet.json` 中加入自定义点击菜单或移动脚本。因此，本仓库额外提供独立的 Windows 互动运行器，并继续复用同一套人物图集。

双击 `启动互动桌宠.bat` 即可运行：

- 按住人物向任意方向拖拽时，会立即朝拖拽方向转身，并使用同一套双腿并拢僵尸跳动作。
- 单击人物，他会进入思考状态，头顶出现 `← ↑ ↓ →` 四个想法。
- 点击任一方向，他会朝该方向转身，以约 130 像素为一步慢速蹦到当前屏幕边缘；到达后会转向，再一步一步沿原路蹦回来。
- 上下移动使用专门的朝上、朝下帧，不会再以正面姿势平移；左右移动也采用双脚同时起跳和落地。
- Windows 透明窗口会在缩放后把半透明边缘硬化为干净透明边，不再与紫色透明键混合成紫色阴影。
- 按 `Esc` 收起想法或让人物回到初始位置。
- 右键人物可以重新打开方向选择、复位或退出。

如果同时显示 Codex 原生宠物，会看到两个角色；使用互动版时可先在 Codex 中隐藏原生悬浮宠物。
